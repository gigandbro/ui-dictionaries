# ui-dictionaries

Набор переводных словарей интерфейсных строк: **русский → английский** и
**русский → украинский**. Обычные JSON-файлы, которые скачиваются по прямым
ссылкам без авторизации:

```
https://raw.githubusercontent.com/gigandbro/ui-dictionaries/main/i18n/en.json
https://raw.githubusercontent.com/gigandbro/ui-dictionaries/main/i18n/uk.json
```

## Формат

```json
{
  "format": 1,
  "language": "en",
  "count": 787,
  "entries": { "Сегодня": "Today", "Введите код": "Enter the code", … }
}
```

- Ключ — исходная строка (русский), значение — перевод.
- `format` — версия формата; потребитель проверяет её перед применением.
- Непокрытые ключи потребитель показывает в оригинале.
- Подстановки вида `{1}`, `{2}` должны совпадать в ключе и переводе.

## Обновление

Словари обновляются проектом-источником после проверки полноты перевода
и плейсхолдеров. Ручные правки будут перезаписаны при следующей публикации.
